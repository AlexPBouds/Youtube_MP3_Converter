# Youtube_MP3_Converter

Convert YouTube links to MP3 files with a simple GUI.

## Features

- Paste a YouTube URL and convert it to MP3
- Choose output quality (bitrate); **Highest (320 kbps)** is the default
- Choose the destination folder; defaults to your **Downloads** folder

## Requirements

```powershell
pip install -r requirements.txt
```

## Run

```powershell
python converter_gui.py
```

The original terminal version is still available via `python converter_cli.py`.
